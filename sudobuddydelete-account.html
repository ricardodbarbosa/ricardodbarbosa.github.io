Delete Account & User Data

In accordance with Google Play's Account Deletion Requirement and data protection regulations (GDPR, CCPA), this page provides clear instructions and an open web resource for users to request the permanent deletion of their SudoBuddy account and associated data.

Application: SudoBuddy Package Name: com.rdba.sudobuddy Developer: Ricardo Barbosa Compliance: Google Play User Data Policy

Method 1: Instant In-App Deletion (Fastest)

If you currently have the SudoBuddy app installed on your Android or iOS device, you can permanently erase your account and all associated cloud data immediately from within the app:

1

Open Settings

Launch SudoBuddy and tap the Settings gear icon located at the top right of the navigation bar.

2

Locate Account

Find the "Detective Profile" section or scroll down to the "Data" management section.

3

Tap Delete Account

Tap the red "Delete Account & Data" button to initiate permanent account erasure.

4

Confirm

Confirm the deletion prompt. Your Firebase account and Firestore leaderboard records are instantly purged.

Method 2: Web Deletion Request (Without Reinstalling)

If you have uninstalled the app or prefer to submit a deletion request from the web, complete the form below. Once submitted, your deletion request will be processed, and all associated cloud records will be permanently removed.

Data Deletion Details

Google Play requires developers to clearly specify what data is removed and what data is retained.

❌ Data That Is Permanently Deleted

  • Authentication Identity: Firebase Authentication user record, unique User ID (UID), and Google OAuth token linkage.
  • Personal Profile: Registered email address, display name / Detective Codename, and Google profile picture avatar.
  • Leaderboard Records: All Daily Sudoku and Daily Murdoku score entries in Google Cloud Firestore (daily_scores collection).
  • Hall of Fame Statistics: Overall cases solved and active streak tallies.
  • Local Device Data: Cleared automatically on in-app deletion (or on app uninstall).

🛡️ Data Retention Policy

  • Zero Personal Data Retained: We do not retain your email, user ID, or any identifying records once account deletion has been processed.
  • Multiplayer Matches: Real-time Speed Duel matches run in server memory (RAM) and are discarded immediately upon match completion.
  • Server Diagnostics: Standard anonymized HTTP server logs (IP address, user agent) are automatically flushed and purged within 30 days.

Processing Timeline

  • In-App Deletion: Takes effect immediately.
  • Web Form Request: Handled within 7 business days (and within a maximum of 30 days pursuant to GDPR / CCPA statutory timelines).
